# 📦 01 — Arrays

Fundamentals of arrays in C++ — creation, traversal, searching, reversing, and pointer-based operations.

## 📄 Files

| File | Description |
|------|-------------|
| `create_array.cpp` | Creating and initializing arrays, `sizeof` to find array length |
| `output_input1.cpp` | Taking array input and printing output |
| `linear_search.cpp` | Linear search — find an element by iterating through the array |
| `binary_search.cpp` | Binary search — efficient search on a sorted array `O(log n)` |
| `find_largest_in_array.cpp` | Finding the largest element in an array |
| `reverse_array_with_extraspace.cpp` | Reversing an array using an extra array |
| `reverse_array_noextraspace.cpp` | Reversing an array in-place (two-pointer approach) |
| `array_pointer.cpp` | Understanding the relationship between arrays and pointers |
| `passedby_ref.cpp` | Passing arrays to functions by reference |
| `pointer_arithmetic1.cpp` | Pointer arithmetic — basics |
| `pointer_arithmetic2.cpp` | Pointer arithmetic — more examples |
| `pointer_arithmetic3.cpp` | Pointer arithmetic — advanced usage |

## 💡 Key Concepts

- Arrays are stored in **contiguous memory locations**
- Array name acts as a **pointer to the first element**
- **Linear Search** → `O(n)` | **Binary Search** → `O(log n)`
- Two approaches to reverse: with extra space `O(n)` vs in-place `O(1)` space
