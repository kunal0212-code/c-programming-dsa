# 🚀 C++ Programming & DSA

A structured collection of C++ programs covering fundamental data structures and algorithms — built as a learning journey from basics to advanced problem-solving.

## 📂 Repository Structure

| #  | Topic | Description | Files |
|----|-------|-------------|-------|
| 01 | [Arrays](./01-Arrays/) | Array basics, searching, reversing, pointers | 12 |
| 02 | [Arrays — Advanced](./02-Arrays-Advanced/) | Subarrays, Kadane's Algorithm, Buy & Sell Stock, Trapping Rainwater | 6 |
| 03 | [2D Arrays](./03-2D-Arrays/) | Introduction to multi-dimensional arrays | 1 |
| 04 | [Sorting Algorithms](./04-Sorting-Algorithms/) | Bubble, Selection, Insertion, Counting Sort | 6 |

## 🛠️ How to Compile & Run

Make sure you have a C++ compiler installed (e.g. `g++`).

```bash
# Compile
g++ filename.cpp -o output

# Run
./output        # Linux / macOS
output.exe      # Windows
```

## 📖 Topics Covered

### 01 — Arrays
- Creating & initializing arrays
- Input / Output operations
- Linear Search & Binary Search
- Reversing arrays (with and without extra space)
- Pointers & pointer arithmetic
- Pass by reference

### 02 — Arrays (Advanced Problems)
- Printing all subarrays
- Maximum Subarray Sum — Brute Force `O(n³)`
- Maximum Subarray Sum — Optimized `O(n²)`
- Maximum Subarray Sum — **Kadane's Algorithm** `O(n)`
- Best Time to Buy & Sell Stock
- Trapping Rainwater

### 03 — 2D Arrays
- Introduction to 2D arrays
- Accessing elements

### 04 — Sorting Algorithms
- Bubble Sort (basic + optimized with early exit)
- Selection Sort
- Insertion Sort
- Counting Sort
- Practice: Sorting characters in descending order
